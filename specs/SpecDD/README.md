Spec DD — Data Lake → .NET migration

This folder contains the draft Spec Design Document (Spec DD) for migrating the current Data Lake ingestion pipeline (SQL Server stored procedures + Mulesoft) into a .NET-based solution.

Files:
- SPEC.md — high level spec and architecture
- DATA_INVENTORY.md — sample files and inferred schemas
- TASKS.md — migration tasks mapped to milestones
- NOTES.md — assumptions, unknowns, and decisions

How to use:
- Iterate on `SPEC.md` for architecture and API shapes
- Attach XSD(s), SP lists, or additional sample files into this folder
- Update `DATA_INVENTORY.md` when new samples arrive
